entries 

Selections of entries: which entries each side of a graph shows, such as the genes of the rows of a heatmap and the metacells of its columns.

A gene selection (e.g., TopMarkers(count=100) ) picks the genes. An entry filter (e.g., OfTypes(types=["T1"]) ) picks some of the entries of an axis; a list of filters picks the entries which pass all of them. Like a property, each holds the values of its arguments, so a form can write it back into the code of its cell. Whether a data source has it, and its value, are implemented separately for each kind of data source. Each is a thin wrapper over a data source of metacellsgraphspy (e.g., get_is_in_categories_vector ), so a graph shown with them is the same as a script calling these data sources.

class metacellswidgets.entries. EntryFilterPicker ( * args , ** kwargs ) [source] 

Pick a filter of the entries of the axis of the source , starting with the current one (if any). The choices are the filters the source has for the axis. The axis may be an AxisPicker to follow. When its axis changes, the filter becomes what EntryFilter.on_axis() says (e.g., an environment becomes a neighborhood on the block axis).

Parameters :

  • source ( SourceWidgets )

  • axis ( str | AxisPicker )

  • current ( EntryFilter | None )
