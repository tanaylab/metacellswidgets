graphs 

The graphs a form can show. Each graph serves all the kinds of data sources which offer it.

The part of a graph which differs between kinds (e.g. building its base graph from the data) is a dispatched method, which each kind implements in its own module (see implements() ).

class metacellswidgets.graphs. GeneGene ( source , * , axis = 'metacell' , x_gene , y_gene , colors = None , sizes = None , tweaks = None ) [source] 

The expression of x_gene against y_gene , a point per entry of the axis , on log scale. The points may be colored by the colors property, and sized by the sizes property.
