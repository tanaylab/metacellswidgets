gene_choices ( * , markers_only = False ) [source] 

The (label, name) of each gene, in the order of the gene axis. Excluded genes are never included. If markers_only , only the marker genes are included. The label is the name followed by the flags of the gene: L (lateral), M (marker), T (transcription factor), R (regulator), F (forbidden), S (skeleton), e.g. Foxa1 M T R . A flag the data set doesn’t have is never shown.
