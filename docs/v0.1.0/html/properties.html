properties 

Properties: the data a form can show in a slot of a graph, such as the colors or the sizes of its points.

A property is a class. Its instance holds the values of its arguments, e.g. GeneExpression("Foxa1") . Each property says what kind of values it produces (its eltype ), and that decides which slots it suits. Whether a data source has a property, and how to fill a graph from it, is implemented separately for each kind of data source.

Some arguments change only how a property is shown, not its data: show_legend , and for a property shown on a log scale, log_base . They mirror the keywords of the property’s data source in metacellsgraphspy , and None leaves the data source’s default. They are the property’s look arguments.

class metacellswidgets.properties. Eltype ( * values ) [source] 

The kind of values a property produces.

NUMBER = 'number' 

Numbers, integer or not, such as UMI counts or gene fractions.

CATEGORICAL = 'categorical' 

Names of categories, such as cell types.

BOOLEAN = 'boolean' 

Boolean flags, such as a mask.

ARRANGEMENT = 'arrangement' 

Numbers which say how to lay out entries (which go together, and in what order), such as a global flow order.

COORDINATE = 'coordinate' 

Positions in an embedding, such as a UMAP, which mean something only relative to each other.
