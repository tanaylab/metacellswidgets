properties 

Properties: the data a form can show in a slot of a graph, such as the colors or the sizes of its points.

A property is a class. Its instance holds the values of its arguments, e.g. GeneExpression("Foxa1") . Each property says what kind of values it produces (its eltype ), and that decides which slots it suits. Whether a data source has a property, and how to fill a graph from it, is implemented separately for each kind of data source.

class metacellswidgets.properties. Eltype ( * values ) [source] 

The kind of values a property produces.

NUMBER = 'number' 

Numbers, integer or not, such as UMI counts or gene fractions.

CATEGORICAL = 'categorical' 

Names of categories, such as cell types.

BOOLEAN = 'boolean' 

Boolean flags, such as a mask.

ARRANGEMENT = 'arrangement' 

Numbers which say how to lay out entries (which go together, and in what order), such as a global flow order.

class metacellswidgets.properties. Property [source] 

The base class of all properties.

A property’s __init__ takes the values of its arguments, and stores each in an attribute of the same name. This is what lets a form write the property back into the code of its cell.

eltype : Eltype 

The kind of values the property produces.

shape : Shape 

The shape of the values the property produces.

VECTOR = 'vector' 

A value per entry of an axis.

class metacellswidgets.properties. Slot ( * values ) [source] 

A place in a graph that a property can fill.

COORDINATES = 'coordinates' 

The coordinates of points along an axis of the graph.

SIZES = 'sizes' 

The sizes of points.

COLORS = 'colors' 

The colors of points, or of an annotation strip.

GROUPS = 'groups' 

Which entries are laid out together, and in what order.

MASK = 'mask' 

Which entries are shown.

HOVERS = 'hovers' 
