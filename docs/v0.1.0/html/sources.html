sources 

Kinds of data sources. Each kind is a class wrapping its data, such as a single Daf data set.

Each kind registers, per axis of its data, the properties a form may offer for that axis. The properties a slot offers for an actual data source are those registered for its kind and axis, which suit the slot, and which the data source has.

class metacellswidgets.sources. SourceWidgets [source] 

The base class of the kinds of data sources.

A subclass also offers the properties registered for its base classes, so a kind can be extended by subclassing it.
