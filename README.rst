metacellswidgets
================

Interactive figures of a metacells repository in Jupyter notebooks.

A form shows one of the figures of `metacellsgraphspy <https://github.com/tanaylab/metacellsgraphspy>`_. Displayed
interactively, it lets you pick the figure's parameters and select points in it. When you are done, it writes your
choices back into the notebook cell, so running the notebook again gives the same figure and the same selection.
