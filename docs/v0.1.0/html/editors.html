editors 

Widgets for editing the arguments of properties and tweaks, shared by all kinds of data sources.

A kind of data source supplies the data these widgets show (e.g., its genes); the widgets don’t depend on the kind. Each widget has an observable value : the editors’ is the property or the tweak (or None while its arguments are incomplete), and the pickers’ is the chosen string (or None while nothing is chosen).

class metacellswidgets.editors. ArgumentsEditor ( * args , ** kwargs ) [source] 

The base class of the widgets editing the arguments of a property or a tweak. Its value is the property or the tweak, or None while its arguments are incomplete. It is is_blank while nothing is picked at all (e.g., a class picked whose arguments are still missing is not blank).

class metacellswidgets.editors. ClassPicker ( * args , ** kwargs ) [source] 

The base class of the widgets picking one of some classes of properties or of tweaks, and editing the arguments of the picked one. The choices start with none. Picking a class whose objects have arguments shows its editor to the right of the choice. The value is the object, or None while nothing is picked or its arguments are incomplete.

A picker may have a default object. While nothing was given or changed, the picker shows the default (picked, with its arguments), and its value stays None until the first change. A “Reset to default” button, shown while the value isn’t None , goes back to showing the default . A given object which isn’t one of the choices (e.g., after the axis changed), or whose arguments aren’t valid, gives way to the default .

A picker may be for the entries of an axis , which may be an AxisPicker to follow. The default may then be a function giving the default object for an axis. When the followed axis changes, the choices change with it. A picker showing its default shows the default of the new axis. A changed picker keeps its object if it is still one of the choices and its arguments are valid for the new axis, and otherwise gives way to the default.

A subclass makes its widget, then calls _show with its choices and the object it starts with. It implements _editor_of , which makes the editor of a choice. A subclass which follows an axis also implements _choices , which gives the choices for the current axis, and may implement _on_axis , which says what the object becomes on the new axis.

Parameters :

  • axis ( None | str | AxisPicker )

  • default ( None | Arguments | Callable [ [ str ] , Arguments | None ] )

class metacellswidgets.editors. ListEditor ( * args , ** kwargs ) [source] 

Edit a list of objects (e.g., properties, tweaks, or names), a row per object, in a collapsible section named title (collapsed at first). Each row is a picker made by make_row , which gets the object the row starts with, or None for a blank row. The list always ends with a blank row; picking something in it makes it a row of the list, and appends a new blank row. Each row of the list has buttons to move it up or down, or to remove it.

The list starts with a row per object of the current list. If there is no current list, it shows the default list (if any), and its value stays None until the first change. Otherwise, the value is the list of the values of the rows, leaving out the rows without one (so it may be empty). A “Reset to default” button, shown while the value isn’t None , sets it back to None and shows the default again.

The list may be of the entries of an axis , which may be an AxisPicker to follow. The default may then be a function giving the default list for an axis. When the followed axis changes, a list showing its default shows the default of the new axis. A changed list keeps its rows, each following the axis by itself (if its make_row gives it the axis picker).

class metacellswidgets.editors. PropertyPicker ( * args , ** kwargs ) [source] 

Pick a property of the source for a slot , for the entries of the axis , starting with the current property (if any). The choices are the properties registered for the source’s kind and the axis, which suit the slot, and which the source has; or none, leaving the slot empty. Picking a property with arguments shows its editor to the right of the choice.

The axis may be an AxisPicker to follow (see ClassPicker ), and the default may then be a function of the axis. An on_axis_change function may decide which property the slot holds when the axis changes.
